# 시연 대본 — 웹캠 디스플레이 (초안)

2026-11-23 작성 · **리허설 전 초안**이다. 시간은 지금 설정값(준비 15초, 부족 8초, 쉬는 시간 30초, 같은 대상 60초, O 3초, '아니요' 12초)으로 계산한 것이고, 리허설에서 디버깅 화면을 보며 고친다.

## 성공 기준
1. 시연자가 추는 동작을 디스플레이가 정확히 분석해서 보여 준다.
2. 캐릭터가 지금 부족한 부분을 정확히 짚는다.

## 준비
- 컴퓨터: 서버 실행(`server/./run.sh`), 브라우저에서 `http://localhost:8000/display`. 인터넷이 필요하다(자세 인식 모델을 CDN에서 받는다).
- 웹캠 권한 허용 → `D`로 디버깅 화면을 열어 스켈레톤이 온몸에 붙는지 확인 → 다시 `D`로 닫는다.
- 분석을 보여 주려면 `L`로 라벨을 켠다: 8 둘레에 부위마다 지금 하는 동작이 크게 뜬다(Left Arm · Reach ↑ 등). 깔끔한 화면만 보여 줄 때는 끈다.
- 서는 자리: 카메라에서 2.5–3m, 화면 가운데, **머리부터 발까지** 화면 안. 카메라를 마주 본다.
- 관객 쪽 화면이 따로 있으면 그 화면에서 디버깅 화면의 `Room` 주소(`/display/<방>`)를 연다. 웹캠을 켠 탭은 하나만 둔다.

## 시간표
| 시간 | 시연자 | 디스플레이에서 보여야 하는 것 |
|---|---|---|
| 0:00–0:05 | 가운데에 가만히 선다 | "Stand still for 3 seconds"와 막대 → 사라짐 |
| 0:05–0:20 | **팔만** 쓴다: 위·옆으로 뻗기, 팔 돌리기. 다리는 그대로, 높이는 중간, 가운데 | 라벨: Left/Right Arm에 Reach ↑ / Circle, 다리는 Hold. 곧 Left Leg에 "less used" |
| 0:15–0:20 | (계속 팔만) | 캐릭터가 희미하게 8 주위를 돌기 시작하고, 물을 때가 가까울수록 또렷해진다 |
| 0:20 | (계속 팔만) | 캐릭터가 8 왼쪽 자리로 내려앉고 "…" 말풍선이 뜬다 |
| 0:21–0:24 | 두 팔로 머리 위에 O를 만들고 3초 유지 | 점이 1초에 하나씩 켜진다 → "How about trying to use your left leg?" |
| 0:25–0:45 | 다리를 쓴다: 발 들기, 왼쪽으로 옆걸음, 다시 가운데 | "You tried it!" · 라벨: Left Leg에 Swing / Reach, Torso에 Travel과 left |
| 0:45–0:50 | 높이를 바꾸지 않고 서서 춘다 | Torso 아래 "Less used: low" |
| 0:50 | (계속) | 다시 "…" |
| 0:51–0:54 | O 3초 | "How about trying to go low?" |
| 0:55–1:10 | 무릎을 굽혀 낮게 내려가 몇 카운트 춘다 | "You tried it!" |

- 캐릭터가 묻는 순서: 가장 오래 부족했던 것부터, 같으면 팔 → 다리 → 높이 → 좌우 순이다. 0:20에는 "왼다리"가 먼저 나온다(팔만 썼고, 다리·높이·좌우가 동시에 부족해지기 시작했기 때문).
- 0:50에 "go low" 대신 "move to your right side"가 나오면 0:25–0:45에 오른쪽으로도 잠깐 갔다 오면 된다(왼쪽만 가면 오른쪽이 부족으로 남는다).
- '아니요'를 보여 주고 싶으면: 질문에 O를 하지 않고 12초 기다린다 → "Maybe later."

## 피할 것
- 제자리 회전, 카메라 쪽으로 뻗기(2D라 보이지 않는다).
- 팔을 몸 뒤로 숨기기, 화면 밖으로 나가기(그 부위는 라벨에 "Not seen"이 되어 짚지 않지만, 팔·다리 비율이 흔들린다).
- 묻기 전부터 머리 위에 O를 하고 있기(묻기 전의 O는 세지 않는다. 내렸다가 다시 올린다).

## 막혔을 때
- 키보드 `Y` = 예, `N` = 아니요.
- 이상하면 새로고침: 새 방에서 처음부터(가만히 3초) 다시 시작한다.
- 카메라가 안 되면 디버깅 화면(`D`)에서 댄스 영상 파일을 넣는다. 영상은 반복 재생되고, 처음 1.5초는 가만히 서 있는 장면이어야 한다.
