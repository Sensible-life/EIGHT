# 계정·동기화·커뮤니티 개발 서버

기존 FastAPI 서버를 실행하면 `/service` API도 함께 실행된다. 계정과 기록 메타데이터는 `server/private_data/service.sqlite3`, 녹화 영상은 `server/private_data/service-media/`에 보관한다. 공개 오디오 파일 디렉터리와 별도로 보관한다. 로그인하지 않으면 타인 게시물을 조회할 수 없으며, 녹화 영상은 업로드한 계정만 다운로드할 수 있다. 기록 저장은 기기에서 버튼을 눌렀을 때 실행되며 영상도 함께 업로드한다. 기기에서 직접 가져온 음악 파일은 업로드하지 않는다.

앱에서는 설정에서 서버 주소를 지정하고 계정 생성 또는 로그인 → 서버 기록 내려받아 병합 → 기록과 영상 저장 순으로 사용한다. 로그인 정보는 현재 실행에만 보관한다. 저장 전 서버의 기록 버전이 바뀌었다면 충돌을 표시하므로 다시 내려받아야 한다. 병합은 기존 기기 기록을 보존하며, 삭제를 다른 기기에 전파하지는 않는다.

서버 주간 미션은 기본 3회이며 운영자는 환경변수 `SERVICE_ADMIN_KEY`를 설정한 뒤 `PUT /service/admin/mission/{YYYY-MM-DD}`에 `X-Admin-Key` 헤더와 `{"title":"...","goal":3}`을 전송해 설정할 수 있다. 신고는 같은 키로 `GET /service/admin/reports`에서 조회한다. 완료는 사용자 기기가 제출하는 재생 시간을 바탕으로 하므로 부정행위 방지 검증은 아니다.

현재 서버는 개발용이다. 공개 운영 전 HTTPS, 계정 복구, 인증 강화, 지속적인 백업, 영상 저장·삭제 정책, 신고 처리 및 서비스 관리가 필요하다. 음원 분석 API와 파일 경로는 기존 개발 서버 정책을 유지한다. 카메라와 워치 백그라운드 동작, iOS 카메라, 실제 기기 테스트도 별도로 필요하다.

검증: `cd server && .venv/bin/python -m unittest tests.test_service tests.test_projection -v`
