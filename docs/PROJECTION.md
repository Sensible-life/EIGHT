# 공간 화면 연결 시제품

현재 앰프/프로젝터의 제어 규격이 정해지지 않아, 분석 서버의 브라우저 화면으로 같은 Wi-Fi 연결을 시험한다. 이 방식은 전용 하드웨어 제어의 대체 규격이 아니다. 네 모서리 수동 보정은 시제품이며 실기기 검증이 필요하다.

1. `server/`에서 `./run.sh`로 서버를 켜고 앱 설정에서 같은 서버 주소를 지정한다.
2. 카메라 탭에서 전신을 보이게 하고 춤 시작 후, 공간 화면 전송을 켠다.
3. 프로젝터에 연결된 컴퓨터/장치의 브라우저에서 앱에 나타나는 `/projection/<방 번호>` 주소를 연다.
4. 투사 화면의 사각 테두리가 바닥에 보이게 한 뒤, 앱에서 **바닥 투사 영역 맞추기**를 누르고 카메라 화면의 해당 네 모서리를 왼쪽 위부터 시계 방향으로 누른다.
5. 앱의 카메라 탭을 닫거나 전송을 끄면 표시가 지워진다. 같은 곡에 대해 다시 켜면 분포는 새로 시작한다.

표시는 보이는 양쪽 발목의 **8×8 위치 분포**다. 보정 전에는 카메라 화면 좌표이고, 네 모서리를 지정하면 원근 변환으로 투사 영역에 맞춘 추정값이다. 발목은 바닥 접점과 다를 수 있고 가림·점프·카메라 시점이 정확도에 영향을 준다. 카메라와 프로젝터를 움직이면 다시 보정해야 한다. 발목이 가려진 프레임은 집계하지 않는다.

웹소켓에는 0~1로 정규화한 64개 공간 집계값, 활성·보정 상태와 촬영 상태를 전달한다. 새 크리에이티브 디스플레이를 위해 관측 가능한 팔·다리의 상대 활동 비율과 트래커가 판단한 덜 사용된 부위도 선택적으로 전달한다. 영상·관절 좌표를 전달하거나 서버에 저장하지 않는다. 3초 동안 갱신이 없으면 브라우저가 표시를 지운다. 현재 로컬 개발 서버에는 인증 및 암호화가 없으므로 신뢰하는 사설 네트워크에서만 사용한다.

The same session can also drive the separate [creative display prototype](CREATIVE_DISPLAY.md), which visualizes aggregate arm/leg activity as an 8 and includes a local Python suggestion workflow. The floor projection remains unchanged.
